# План сборки

Порядок важен: каждый шаг опирается на предыдущий.

## Шаг 0. Подготовка ассетов

1. `pip install pillow numpy`
2. `python tools/build_muscle_map.py`
   Скрипт берёт базы и маски из `muscle_map`, вычисляет зоны по разнице с базой и складывает результат в `assets/map`. В конце печатает долю площади каждой зоны: значения меньше 0.3 или больше 12 процентов означают, что маска не совпала с базой.
3. Скопировать семь файлов маскота в `assets/mascot` под именами без суффикса: `avatar.png`, `card_main.png`, `empty.png`, `finish.png`, `tile_exercises.png`, `tile_program.png`, `tile_stats.png`. Если фон на них не прозрачный, убрать его тем же способом, что и у баз карты: он ровный.
4. Нарезать иконку `app_icon 1.png` в `assets/icons`: 180, 192, 512 и маскируемый вариант 512 с полями 10 процентов.

## Шаг 1. Каркас

`index.html`, `src/tokens.css`, `src/app.css`, `src/store.js`, `src/data.js`, роутер по хешу. Экранов ещё нет, есть пустой каркас и шапка.

Хранение: IndexedDB как основное, localStorage как зеркало для мелких ключей. Схема версионируется. Экспорт и импорт файлом через стандартное меню системы.

## Шаг 2. Главный экран и тренировка

Главный: шапка, чипы недели и даты, карточка ближайшей тренировки, три плитки, строка резервной копии.
Тренировка: список свёрнутых плашек, разворот в карточку, строки подходов, степперы, отметка выполнения, замена упражнения, кнопка завершения упражнения, нижняя полоса с отдыхом или кнопкой завершения тренировки.

Здесь же: перенос веса с плашкой подтверждения, таймер отдыха по упражнениям, экран не гаснет во время тренировки.

## Шаг 3. Завершение и статистика

Экран завершения, затем четыре вкладки статистики и история с подробностями тренировки.

## Шаг 4. Программа, упражнения, настройки

Редактор дня, справочник упражнений с созданием своих, настройки с резервной копией и сбросом.

## Шаг 5. PWA и публикация

Часть А: `manifest.webmanifest`, `sw.js` с версией кэша, иконки (недостающие делает `tools/prepare_pwa_icons.py`), метатеги для айфона, запасные шрифты без сети, оповещение других вкладок (`src/sync.js`), запрос постоянного хранилища, проверка установки на домашний экран.
Часть Б: публикация на GitHub Pages, репозиторий `vault-tec-gym`, ветка `main`, корень. Как выкладывать изменения: `docs/PUBLISH.md`.

## Приёмка

1. Тренировка проходится целиком без ошибок в консоли.
2. Значения переносятся на следующую тренировку так, как описано в спецификации.
3. После перезагрузки страницы незавершённая тренировка продолжается.
4. Приложение открывается без сети.
5. Резервная копия сохраняется и восстанавливается.
6. Нет горизонтальной прокрутки на 390 и 430.
