# MILO 2.0 · спецификация функционала и программы

**Статус:** функционал и программа согласованы 17 сентября 2026. Макет из 25 артбордов согласован 22 сентября 2026, лежит в артефакте Claude Design (см. раздел 17). Следующий этап: генерация ассетов, затем программирование с нуля.

Документ заменяет `claude/milo-spec.md` (версия 1.1.0) и `claude/milo-redesign-fallout-brief.md`. Оформление в стиле Fallout снято, код 1.1.0 используется только как справка по логике.

## 1. Порядок работы

1. Функционал и программа (этот документ). Готово.
2. Визуал: генерация в Nano Banana (Gemini, подписка Google AI Pro), одна тема, мышечная карта. Выполняет пользователь.
3. Разбор визуала: цвета, шрифты, отступы, компоненты, проверка контраста. Выполняет Claude.
4. Программирование с нуля. История тренировок из 1.1.0 не переносится.

## 2. Платформа и название

**Название приложения: VAULT-TEC GYM.** Оно выводится в шапке главного экрана и используется в иконке на домашнем экране.

* PWA на GitHub Pages, ярлык на домашнем экране iPhone, работа без интернета.
* Без сети работает всё: все экраны, карта, графики, тренировка от начала до завершения, резервная копия.
  Файлы приложения хранит service worker (`sw.js`); новая версия скачивается при запуске с сетью
  и применяется при следующем полном запуске, открытое приложение не перезагружается посреди тренировки.
* Данные хранятся на телефоне. Сервера, аккаунта и синхронизации нет.
* После первой сохранённой тренировки приложение один раз просит браузер хранить данные постоянно.
  Ответ браузера виден в настройках строкой «Хранилище».
* Если приложение открыто в двух вкладках, удаление данных, загрузка копии и новый цикл в одной
  перезагружают другую на главный экран, чтобы она не записала старое состояние обратно.
* Одна тема оформления.
* Удаление ярлыка с домашнего экрана удаляет данные, поэтому резервная копия обязательна (раздел 10).

## 3. Главный экран

Пять плиток, крупные прямоугольники, на каждой название и одна строка актуальных данных. Настройки открываются иконкой в углу.

| Блок | Содержимое |
|---|---|
| Шапка | название приложения VAULT-TEC GYM, аватар, кнопка настроек |
| Чипы | номер недели цикла (при разгрузочной неделе пометка), дата |
| Главная карточка | ближайшая тренировка: название дня, тип дня, прошлая тренировка, число упражнений, кнопка "Начать"; при незавершённой тренировке "Продолжить" и прогресс |
| Плитка "Программа" | название и слот под изображение 80×80 |
| Плитка "Упражнения" | название и слот под изображение 80×80 |
| Плитка "Статистика" | название и слот под изображение 80×80, во всю ширину |

Мелкие строки с данными в плитках не выводятся. Отдельной плитки веса тела нет: вес входит вкладкой в статистику.

Дополнительно на главном экране: напоминание о резервной копии, если последней копии больше 7 дней.

## 4. Даты и выбор тренировки

* Дата берётся из телефона, интернет не нужен.
* Сегодня ПН, СР или ПТ: предлагается тренировка этого дня.
* День отдыха: показывается ближайшая тренировка с датой, начать можно в любой момент.
* Прошлая тренировка по расписанию пропущена: плашка с выбором "Сделать пропущенную" или "Сделать по расписанию". Дни сами не сдвигаются.
* Незавершённая тренировка: плитка "Продолжить". Если прошло больше 12 часов, предложение завершить с тем, что отмечено.
* Тренировка через полночь записывается на дату начала.
* Любой из трёх дней можно выбрать вручную, запись идёт на фактическую дату.
* Пропуски учитываются в общей статистике.

## 5. Экран тренировки

**Шапка:** название дня полностью ("Верх тела · тяговый день"), общий таймер, прогресс "3 из 8", кнопка выхода. Сокращений дней недели в интерфейсе нет.

**Список упражнений:** сворачиваемые карточки, номер, название, состояние (не начато, в процессе, выполнено).

**Разминка:** отдельный тип пункта, только таймер (15 или 30 минут), без подходов и весов.

**Открытая карточка упражнения, сверху вниз:**

1. Мышечная карта: основная группа ярко, вспомогательные приглушённо.
2. Краткая статистика: прошлый результат, личный рекорд, изменение рабочего веса за месяц.
3. Отметка "Диапазон выполнен", если в прошлый раз во всех рабочих подходах достигнут верх диапазона.
5. Разминочные подходы, затем рабочие. В строке: вес со степпером, повторы со степпером, кнопка "Выполнено".
6. Для подтягиваний, обратных подтягиваний и обоих отжиманий на брусьях поле "Дополнительный вес", по умолчанию 0.
7. Для упражнений одной рукой подпись "на каждую руку", значения вводятся одним числом.
8. Кнопки "Добавить подход", "Удалить подход".
9. Кнопки "Заменить упражнение" и "Завершить упражнение". Вторая закрывает упражнение раньше запланированного числа подходов.
10. Таймер отдыха упражнения.

**Два состояния экрана.** Сначала показывается список всех упражнений тренировки свёрнутыми плашками: номер, название, состояние (выполнено с итогом, текущее, не начато). Нажатие разворачивает плашку в карточку, описанную выше. Нижняя полоса имеет два состояния: обратный отсчёт отдыха, пока идёт отдых, и кнопка "Завершить тренировку" в остальное время.

**Состояния строки подхода:** ожидает, выполнено, пропущено. Разминочная строка оформлена отдельно.

## 6. Перенос результатов на следующую тренировку

Методически это двойная прогрессия с ручным решением о прибавке.

* Значения по умолчанию берутся из прошлой тренировки этого упражнения.
* Разминочные подходы переносятся по порядку.
* Рабочие подходы получают вес, подтверждённый в прошлый раз.
* Число подходов переносится.
* Невыполненные подходы не переносятся и не идут в статистику.
* **Плашка переноса.** Появляется, когда подход отмечен выполненным и его вес отличается от подставленного (нажатия степпера плашку не вызывают). Текст: "Вес изменён: 16 → 18 кг. Поставить 18 кг на следующую тренировку?"
  * "Да": в следующий раз 18 кг во всех рабочих подходах упражнения.
  * "Нет, только сегодня": остаётся прежний вес.
  * Для разминочного подхода перенос касается только этого подхода.
  * При нескольких изменениях действует последний ответ.
* Повторы переносятся без вопроса.
* Все принятые переносы собраны на экране завершения, там их можно отменить.
* Автоматической прогрессии весов нет: решение о прибавке принимает пользователь.

## 7. Замена упражнения

* Кнопка "Заменить" открывает список: сначала упражнения на ту же основную группу, затем остальные, внизу "Создать упражнение".
* В первой версии список состоит из упражнений программы и упражнений, созданных пользователем. Заранее заполненного справочника нет.
* Форма создания: название и основная группа обязательны, вспомогательные группы по желанию, диапазон повторов и отдых по умолчанию.
* После выбора плашка: "Только сегодня" или "Навсегда в программе".
* У каждого упражнения своя история и свои веса.

## 8. Таймер отдыха

* У каждого упражнения своё время отдыха (значения в программе, раздел 13).
* Запускается автоматически после отметки подхода.
* Изменённое в карточке время запоминается для упражнения.
* Во время отдыха внизу экрана полоса обратного отсчёта, видна при свёрнутой карточке.
* Сигнал: звук и вибрация, если iOS разрешит.
* Экран не гаснет во время активной тренировки (включено по умолчанию, выключатель в настройках). Причина: в фоне и при заблокированном экране PWA на iOS приостанавливается, сигнал может не прозвучать.

## 9. Экран завершения

* Длительность, число рабочих подходов, тоннаж (сумма вес × повторы).
* Мышечная карта с подсветкой проработанных групп и числом рабочих подходов на каждую.
* Изменения по каждому упражнению относительно прошлой тренировки: вес вырос, остался, снизился, с цифрами.
* Новые рекорды: максимальный вес, максимум повторов на весе, лучший расчётный максимум.
* Замены упражнений.
* Перенесённые веса с возможностью отмены.

## 10. Настройки

* Звук сигнала, вибрация.
* Экран не гаснет.
* Шаг степпера веса (общий, значение можно ввести вручную).
* Сохранить копию: файл через стандартное меню iOS в "Файлы" или iCloud Drive.
* Восстановить из копии.
* Напоминание о копии раз в 7 дней.
* Начать цикл заново.
* Сброс данных.

## 11. Статистика

Статистика состоит из четырёх вкладок: "Упражнение", "Группы мышц", "Общая", "Вес тела". История тренировок входит в раздел отдельным списком.

**По упражнению:** график рабочего веса, график расчётного максимума, тоннаж, таблица тренировок, рекорды. Период: месяц, три месяца, всё время.

**По группам мышц:** недельный объём дробным подсчётом (прямой подход 1, вспомогательный 0.5) и зона:

| Подходов в неделю | Зона |
|---|---|
| меньше 6 | мало |
| 6…9 | поддержание |
| 10…20 | рост |
| больше 20 | высокий объём |

**Общая:** тренировки по неделям, пропуски, средняя длительность.

**История:** список тренировок, подробности каждой.

**Расчёты:**

* Расчётный максимум по формуле Эпли: вес × (1 + повторы / 30).
* Для упражнений с собственным весом в расчётах используется вес тела плюс дополнительный вес. Если вес тела не записан, график строится по повторам.

## 12. Вес тела (вкладка статистики)

* Быстрый ввод с плитки и в разделе, дата автоматически.
* График.
* Изменение за неделю, месяц, с начала записей.
* Относительная сила: рабочий вес в ключевых упражнениях, делённый на вес тела.

## 13. Программа

**Структура:** трёхдневный вариант схемы верх и низ. Понедельник верх тела, жимовой день (тяжёлый). Среда ноги. Пятница верх тела, тяговый день (объёмный).

**Цикл 8 недель** (по модели Generic Bulking Routine Лайла Макдональда):

* недели 1…2 входные, без подходов до отказа;
* недели 3…7 нарастание;
* неделя 8 разгрузочная: число рабочих подходов в каждом упражнении умножается на 2/3 с округлением, минимум 1; веса без изменений;
* номер недели считается от первой тренировки цикла, после 8 недели цикл начинается заново.

**Рабочие подходы:** запас 1…2 повтора. Разминочный подход ставится перед первым упражнением на группу мышц (жим на наклонной, подтягивания, становая тяга, гак присед, отжимания на брусьях), число можно менять в тренировке.

## 15. Модель данных (черновик для программирования)

* **Упражнение:** id, название, основные группы (1…2), вспомогательные группы, тип (силовое, разминка), с собственным весом (да, нет), одной рукой (да, нет), диапазон повторов, отдых, дата создания, пользовательское (да, нет).
* **День программы:** день недели, полное название, тип дня, упорядоченный список пунктов: упражнение, число разминочных подходов, число рабочих подходов.
* **Задание на следующий раз (по упражнению):** веса и повторы разминочных подходов по порядку, рабочий вес, повторы, число рабочих подходов, дополнительный вес.
* **Тренировка:** id, дата начала, дата окончания, день программы, неделя цикла, разгрузочная (да, нет), список выполнений упражнений, замены, принятые переносы.
* **Подход:** тип (разминочный, рабочий), вес, дополнительный вес, повторы, состояние, время отметки.
* **Вес тела:** дата, значение.
* **Цикл:** дата начала.
* **Настройки:** звук, вибрация, экран не гаснет, шаг степпера, дата последней копии.
* Схема данных версионируется, чтобы будущие обновления не теряли историю.

## 16. Не входит в первую версию

* Заранее заполненный справочник упражнений для замен.
* RPE и заметки.
* Облачная синхронизация.
* Автоматическая прогрессия весов и подсказки о прибавке.
