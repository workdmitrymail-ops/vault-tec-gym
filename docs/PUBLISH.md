# Как выложить изменения

Сайт: https://workdmitrymail-ops.github.io/vault-tec-gym/
Репозиторий: https://github.com/workdmitrymail-ops/vault-tec-gym

Сайт собирается сам из ветки `main`. Выложить изменения значит поднять номер версии, сохранить изменения в git и отправить их на GitHub. Через пару минут телефон получит новую версию.

## Один раз на компьютере

Нужны Git и GitHub CLI, вход в GitHub уже выполнен. Проверить:

```
git --version
gh auth status
```

Если `gh auth status` пишет, что вход не выполнен, выполните `gh auth login` и следуйте подсказкам.

## Каждый раз, когда что-то поменяли

Все команды выполняются в терминале, открытом в папке проекта (там, где лежит `index.html`).

**1. Поднимите версию в двух файлах, одинаково.**

В `src/store.js` строка:

```
export const APP_VERSION = '2.0.0';
```

В `sw.js` строка:

```
const VERSION = '2.0.0';   // равна APP_VERSION в src/store.js
```

Поменяйте номер в обоих местах на один и тот же, например `2.0.1`. Последняя цифра для исправлений, средняя для новых возможностей.

Без новой версии телефон изменений не увидит: приложение хранит файлы у себя и сверяется с сайтом только по номеру версии.

**2. Проверьте, что ничего не сломалось.**

```
python -m http.server 8080 --bind 127.0.0.1
```

Откройте в браузере http://localhost:8080/tools/logic_test.html. Вверху должно быть «Пройдено N из N». Если есть «Не пройдено», не выкладывайте, сначала исправьте. Остановить сервер: Ctrl+C в терминале.

**3. Сохраните изменения и отправьте на GitHub.**

```
git add -A
git status
```

`git status` покажет список файлов, которые уйдут на сайт. Посмотрите, что в нём нет ничего лишнего, например резервных копий с тренировками. Затем:

```
git commit -m "Версия 2.0.1: коротко, что изменилось"
git push
```

**4. Подождите сборку.**

Обычно одна-две минуты. Проверить:

```
gh run list --limit 1
```

Когда в строке появится `completed` и `success`, сайт обновлён. То же видно на странице https://github.com/workdmitrymail-ops/vault-tec-gym/actions: зелёная галочка у последней сборки.

**5. Обновите приложение на телефоне.**

Откройте приложение при включённом интернете. В Настройках, в блоке «О приложении», появится строка «Обновление: загружено». Закройте приложение полностью (смахните его вверх в переключателе приложений) и откройте снова. В строке «Версия» будет новый номер.

Приложение не обновляется посреди работы намеренно: идущая тренировка не прервётся, новая версия включится при следующем запуске.

## Если что-то пошло не так

- `git push` отвечает, что на GitHub есть изменения, которых нет у вас: выполните `git pull --rebase`, затем снова `git push`.
- Сайт открылся, но телефон показывает старую версию: проверьте, что номер поднят в обоих файлах и одинаковый. `tools/logic_test.html` это сверяет.
- Нужно вернуть прошлую версию: поднимите номер ещё раз (например, `2.0.2`) и выложите исправленные файлы. Номер версии только растёт, иначе телефон не поймёт, что есть обновление.
