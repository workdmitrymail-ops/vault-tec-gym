# Стиль VAULT-TEC GYM

Источник: артборды с пометкой "СТИЛЬ VAULT" в макете Claude Design и гайд по визуальному стилю в корне папки. Все значения уже перенесены в `src/tokens.css`, этот документ объясняет, как их применять.

## Палитра и роли

| Цвет | Значение | Роль |
|---|---|---|
| Фон | #F4F6F3 | подложка экрана |
| Карточка | #FFFFFF | все карточки и плитки |
| Линия | #D8DED6 | границы кнопок, чипов, степперов, разделители |
| Текст | #0C2413 | основной |
| Приглушённый | #4C6B54 | подписи и второстепенные данные |
| Акцент | #00B03C | заливка кнопок, чипов и выбранных вкладок, шапка главного экрана, данные графиков и полос объёма, рамка, полоса и скобки активной карточки, зоны мышечной карты |
| Акцент, нажатие | #009433 | только состояние нажатия зелёной кнопки |
| Отметка | #FCD94C | только заливка редких отметок, текст на ней #2A2100 |
| Опасное | #B3261E | только удаление и сброс данных |
| Недоступно | #E8EBE7, текст #5C6A5E | неактивные кнопки: плоская заливка без тени, текст по общему правилу не ниже 4.5:1 |

Синего и тёмно-зелёных оттенков в палитре нет, решение владельца проекта.

Правило: на одном экране акцент не более чем на трёх элементах. Жёлтым текст не набирается. Зелёным текст на светлом фоне не набирается: для текста только `--c-text` и `--c-muted`.

## Контраст

Текст не ниже 4.5:1, графические элементы не ниже 3:1. Исключение, решение владельца проекта: белый текст на заливке `--c-accent` (#00B03C, 2.89:1) и графические элементы цвета `--c-accent` на светлом фоне (2.89:1 на белом). Исключение касается только этого цвета.

## Шапка главного экрана

Плашка цвета `--c-accent`, скругление `--r-card`. Название VAULT-TEC GYM белым, начертание 600, кегль роли заголовка в шапке. Справа белая подложка `--c-card` по форме кругов, внутренние отступы 6 px, между кругами 10 px. В ней два круга по 44 px: фон `--c-sunken`, граница 1 px `--c-line`. Левый круг аватар, правый ведёт в настройки: контурная шестерёнка цветом `--c-text`, толщина линии 1.5.

## Подача

Неоморфная: карточки без границ, с двойной тенью, светлая сверху слева и тёмная снизу справа. Значение тени в токене `--shadow`, менять только там.

Исключение ради читаемости в зале: у кнопок, чипов, степперов и строк подходов граница 1 px цветом линии остаётся всегда.

Активная карточка упражнения: граница акцентом, акцентная полоса 5 px слева и угловые скобки 14 px во всех углах.

Единственное значение вне токенов: высота окна `100vh` и `100dvh` в `src/app.css`, это размер экрана, а не оформления.

## Типографика

Geologica для заголовков и текста, JetBrains Mono для цифр, данных и таймеров. Роли и кегли в токенах, отдельная роль для табло таймера 56 на 60.

Без сети вместо них запасные гарнитуры из `src/tokens.css`: `Geologica Fallback` на Arial и `JetBrains Mono Fallback` на Menlo или Courier New, с `size-adjust` и подогнанными высотами для каждого начертания. Переносы строк и высоты блоков те же, меняется только рисунок букв.

## Мышечная карта

База это картинка с прозрачным фоном, зоны это белые фигуры на прозрачном фоне, маска по альфа каналу. Зона красится цветом через `mask-image`: основная группа акцентом, вспомогательные тем же цветом с непрозрачностью 35 процентов.
