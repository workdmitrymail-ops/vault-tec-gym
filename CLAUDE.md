# VAULT-TEC GYM · инструкция для сборки

Личное приложение для тренировок. PWA, устанавливается на домашний экран iPhone, работает без сети, данные хранятся на устройстве.

Читать перед работой: `docs/SPEC.md` (функционал и программа), `docs/STYLE.md` (стиль и токены), `docs/BUILD_PLAN.md` (порядок сборки).

## Стек

Чистые HTML, CSS и JavaScript, без фреймворков и без сборщика. Модули ES. Ничего не устанавливать в проект, кроме Python с Pillow и numpy для разовой подготовки мышечной карты.

Причина: приложение должно открываться с GitHub Pages как статика и работать без сети.

## Правила

1. Цвета, радиусы, тени и кегли берутся только из `src/tokens.css`. Значений в коде экранов быть не должно.
2. Шрифты Geologica и JetBrains Mono подключаются с Google Fonts только при сети. Без сети работают
   запасные системные шрифты с подогнанными метриками из `src/tokens.css`, вёрстка не сдвигается.
3. Цифры и данные набираются моноширинным, заголовки и текст гротеском. Внутри одной строки один шрифт.
4. Сокращений дней недели в интерфейсе нет.
5. Зона нажатия не меньше 44 px. Контраст текста не ниже 4.5:1, графических элементов не ниже 3:1.
   Единственное исключение, зафиксированное решение владельца проекта, обратно не откатывать:
   белый текст (`--c-on-accent`, #FFFFFF) на заливке `--c-accent` (#00B03C) и графические элементы
   цвета `--c-accent` (#00B03C) на светлом фоне допускаются при контрасте 2.89:1.
   Исключение распространяется только на этот цвет. Зелёный текст на светлом фоне по-прежнему запрещён:
   для текста используются `--c-text` и `--c-muted`. Синего и тёмно-зелёных оттенков в палитре нет.
6. Разметка честная: `button`, `a`, `input` с `label`, подписи для иконок.
7. Никакой автоматической прогрессии весов. Приложение только переносит подтверждённые значения.
8. Данные пользователя не теряются при обновлении: схема версионируется, миграции пишутся явно.
9. Любое изменение файлов приложения выпускается новой версией: поднять `APP_VERSION` в `src/store.js`
   и `VERSION` в `sw.js` на одно и то же значение. Установленное приложение берёт файлы из кэша и без
   новой версии изменений не увидит. Новый файл приложения добавить в список `SHELL` в `sw.js`.
   `tools/logic_test.html` сверяет обе версии и полноту списка. Как выложить изменения на сайт: `docs/PUBLISH.md`.

## Проверка перед каждым шагом

Открыть на ширине 390 и 430, проверить отсутствие горизонтальной прокрутки, читаемость цифр, работу без сети после первой загрузки.

Service worker отдаёт файлы из кэша, поэтому при разработке правки в браузере видны только после
новой версии или после сброса: в инструментах разработчика Application, Service workers, Unregister
и Clear storage. Страницы из `tools/` воркер не обслуживает, проверки всегда видят текущие файлы.
